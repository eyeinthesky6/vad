# The Agent-Native Document Manifesto

Documents are changing.

For decades, documents were designed primarily for humans. They were written, printed, emailed, signed, archived, and occasionally searched.

PDF became successful because it solved a major problem: it made appearance portable.

But AI agents do not need documents to merely look the same.

Agents need documents that can be understood, verified, reasoned over, and acted upon safely.

A document for the agent era should not be only a frozen page.

It should carry:

- content
- meaning
- provenance
- permissions
- trust state
- version history
- machine-readable claims
- human-readable fallback

PDF preserved appearance.

Agent-native documents should preserve meaning.

This does not mean visual documents disappear. Humans will still need readable views, printable outputs, and final exports.

But the source of truth should no longer be a visual artifact that agents must reverse-engineer.

The source of truth should be structured, portable, inspectable, and verifiable.

An agent-native document should answer:

- What is this document?
- What does it claim?
- Where did it come from?
- Who or what created it?
- Has it changed?
- Which parts are trusted?
- What may an agent do with it?
- What must an agent refuse to do?

VAD is an experimental attempt to explore this idea.

It is not a final standard. It is not a replacement for all document formats. It is not a legal signing framework.

It is a starting point for a future where documents are no longer just files people read, but trusted knowledge objects that humans and agents can share.
