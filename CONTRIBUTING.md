# Contributing to VAD

VAD is an experimental open proposal. Contributions are welcome.

Useful contribution areas:

- improve the preliminary specification
- challenge assumptions
- add examples
- improve schemas
- propose trust-state behavior
- explore relationship with existing standards
- build validators
- build viewers
- build agent readers

## Contribution principles

- Keep the format lightweight.
- Prefer inspectable text files over opaque binaries.
- Do not introduce platform lock-in.
- Do not make production security claims without a threat model.
- Treat PDF, EPUB, DOCX, C2PA, COSE, and Verifiable Credentials as related work, not enemies.

## Current scope

VAD 0.1 is intentionally small. It is a concept and preliminary specification, not a complete implementation.
